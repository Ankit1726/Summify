# 🌟 About Summify

**Summify** is an **AI-powered text summarization application** built using a **fine-tuned T5 Transformer model**.

The application takes long-form text as input and generates a concise and meaningful summary using a custom-trained sequence-to-sequence model.

Instead of manually reading large amounts of content, users can provide text and let the fine-tuned model extract the most important information.

### What Summify Can Do

- 📝 Summarize long text
- 🤖 Generate AI-powered summaries
- 🧠 Use a fine-tuned T5 Transformer
- ⚡ Provide fast inference through FastAPI
- 🎨 Provide a modern dark animated UI
- 🐳 Run using Docker
- ☁️ Deploy easily on Render
- 🔌 Expose a REST API for summarization
